# T34M ROOKIE Study Archive

T34M ROOKIE 보안 스터디에서 진행한 CTF 및 보안 문제 풀이를 정리하는 저장소입니다.

## Repository Structure

```text
T34M-ROOKIE-Study-Archive/
├── README.md
├── weekly-challenges/
│   ├── week-01/
│   ├── week-02/
│   ├── week-03/
│   └── ...
└── members/
    ├── github-id-1/
    ├── github-id-2/
    ├── github-id-3/
    └── ...
```

## Weekly Challenges

`weekly-challenges/`에는 스터디에서 매주 선정한 공통 문제와 관련 자료를 정리합니다.

```text
weekly-challenges/
└── week-01/
    ├── README.md
    └── ...
```

각 주차별 README에는 해당 주의 공통 문제 목록과 기본 정보를 작성합니다.

## Member Write-ups

`members/`에는 각 스터디원이 직접 작성한 Write-up을 저장합니다.

```text
members/
└── github-id/
    ├── README.md
    ├── Dreamhack/
    ├── CTF/
    └── ...
```

각자의 GitHub ID를 폴더명으로 사용합니다.

## Write-up Format

Write-up은 자유롭게 작성하되 다음 내용을 포함하는 것을 권장합니다.

```text
문제 정보
취약점 또는 핵심 아이디어
분석 과정
풀이 과정
Payload / Exploit
결과
```

이미지가 필요한 경우 문제 폴더 내부에 `images/` 디렉터리를 생성하여 관리합니다.

```text
problem-name/
├── README.md
└── images/
    ├── 01.png
    └── 02.png
```

Markdown에서는 다음과 같이 사용할 수 있습니다.

```md
![description](./images/01.png)
```

## Study

공통 문제는 매주 진행하며, 각 스터디원은 자신의 풀이 과정을 Write-up으로 작성합니다.

동일한 문제를 풀더라도 풀이 과정과 접근 방법은 각자 자유롭게 작성합니다.
